# APEX SWARM

Distributed multi-agent AI orchestration platform powered by MiMo V2.5 + Hermes Agent.

## Architecture
- **Coordinator** — Task decomposition & agent assignment
- **Scout** — Resource discovery & optimal execution paths
- **Worker** — Parallel task execution across 200+ APIs
- **Guard** — Error detection & automatic recovery
- **Analyst** — Performance metrics & continuous optimization

## Tech Stack
- MiMo V2.5 (long chain-of-thought reasoning)
- Hermes Agent (orchestration layer)
- Claude series (language understanding)
